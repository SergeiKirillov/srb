## Getting Started

на основании ветки 'О Flutter' предлагаю перейти к разработке программы о Смене по следующему плану. Внешний вид приложения должен быть для начала простым, без фото 
- начальный экран. Простой интерфейс: текущая дата, текстовое поле смены 1 под ним кнопка номера бригады которая работала в ночь , ниже текстовое поле смены 2 и кнопка с надписью номера бригады которая работает в день.Возле текущей даты стрелочки для перемещения на один день вперед и на один день назад. При нажатию на текущею дату открывается календарь где можно выбрать любой день, месяц и год. При загрузке календаря нужно учитывать официальные праздничные дни. При нажатии на кнопку мы перемещаемся на второй экран с выбранной бригадой
- второй экран - информация выбранной бригаде
  - поле для фильтра по цеху, по раб. месту , по службе
  - вывод всех работников по этой бригаде
  - Работник это кнопка при нажатии на которую открывается третий экран с информацией по работнику
- третий экран
  - информация по работнику
    - ФИО
    - Цех
    - подразделение
    - должность
    - раб место
    - кнопки позвонить на разные телефоны
      - может быть от нет телефона до нескольких
      - телефон может быть как сотовый 11- значный, так и 6 значный, и 3 значный
        - если 6 значный то дополнить его кодом города
        - если 3 значный то вывести его в виде кнопки, но без возможности нажатия
    - Кнопки поделиться контактом
- экран настройки в меню
  - загрузить базу номеров в формате json
  - выгрузить базу в файл json
  - добавить нового рабочего в базу
  - просмотр всех данных с базы с возможностью редактирования
- Создание виджета для размещения на главном экране который будет показывать только номер бригады которая работает сегодня . При нажатии на виджет открывается приложение со 2 экрана(список людей работающих в этой бригаде)
В процесс создания приложения сделать в виде подробного обучающего курса

теперь предлагаю рассмотреть выриант рабочего телефона. 
для визуального отображения желательно сохранить 6 цифр разделённых по парам при этом 1 пара не меняется 96, но для того чтобы его добавить в программу для того чтобы звонить предлагаю вставить перед номером код города +77213. Т.е. к примеру у нас номер 96 03 27. Но в номернабирать отправляем +77213960327. 

Код  города поместим в отдельный справочник, который можно будет дополнять и редактировать.
в карточку  работника добавим адрес который будет состоять из списка города(справочник), улицы,  дома и квартиры. При этом эти поля могут быть пустые за исключением города. Город по умолчанию Темиртау и код города +77213. При наборе будет соединяться код города и рабочий номер номер.
