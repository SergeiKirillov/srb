## Проверка перед сборкой на новом ПК
Выполняйте команды из корня проекта:
1. Проверить Flutter:
`flutter --version`
2. Проверить Java:
`java -version`
3. Проверить зависимости:
`flutter doctor -v`
`flutter pub get`
4. Проверить проект:
`flutter analyze`
5. Проверить Debug-сборку:
`flutter build apk --debug`
6. Проверить Release-сборку:
`flutter build apk --release`
